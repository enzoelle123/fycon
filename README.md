# FyCon · MVP3 funcional

Site público: https://enzoelle123.github.io/fycon/

O FyCon reúne congressos e eventos acadêmicos de diferentes instituições em um só lugar. Esta é a versão funcional (MVP3) construída após o Ciclo 2 de validação.

Protótipo acadêmico. Os eventos, organizadores e links são fictícios. Favoritos, agenda, alertas e preferências ficam salvos apenas no navegador de quem usa. Nada é enviado a servidor.

Feito com React, TypeScript e Tailwind (build estático em um único arquivo).

Equipe: Enzo Alle, Guilherme Dias, Silvio Cesar, Lucas Bertoli e Murilo Carvalho.
